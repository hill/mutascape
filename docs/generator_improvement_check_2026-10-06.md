# Additional protein check

HIV-1 protease supplies an additional protein for the candidate study.
The choice follows input availability and residue coverage, before inspection of candidate search outcomes.
All 1,175 measured genotypes form one connected search space.
Its 14 WT and single-site observations cover every substitution used in this search space.
The local HIV-1 b0.5 alignment covers every experimental site and matches the full wild-type sequence.

Fit the same official Mogwai model for 1,000 steps with the existing optimisation settings.
Run every candidate, without changing its settings after the three-protein experiment.
Retain every external comparator and Mutascape control from that experiment.
Use the same twelve search methods, 48 and 96 evaluations, five landscape samples and six campaign repeats per sample.
Fixed models receive thirty repeats.
Use measured multi-mutant values only for reference campaigns and evaluation.

This protein appeared in earlier project evaluations.
It is an additional check of the fixed candidate mechanisms, rather than an untouched test of the whole project.
Report its results separately from the three proteins that motivated this study.
